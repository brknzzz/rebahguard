RebahGuard · HP Edge

Mode: RebahGuard

Jadikan HP ini edge device RebahGuard nyata tanpa Termux. Halaman membaca accelerometer dan gyroscope melalui DeviceMotionEvent, menghitung overhead_deg, roll_deg, motion_rms (bebas bias), serta gyro_rms, lalu terhubung dua arah ke MQTT Broker.

Broker pribadi (opsional)

Harus dibuka lewat HTTPS. Saat klik Mulai membaca sensor, izin sensor gerak, Web Audio, dan Screen Wake Lock akan diaktifkan otomatis.
